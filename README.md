# clf-fs
## Разработка нейросетевого классификатора оценки ФС
Научно-исследовательская составляющая проекта Антропоцентричный ИИ. Разработка направлена на создание нейросетевого метода распознавания состояний утомления/дремоты на основе анализа ЭЭГ/аудио сигналов с учетом их индивидуальных характеристик. Результатом разработки являются I) нейросетевой модуль для встраивания в сервис мониторинга ФС, II) публикации/доклады.  

### Этапы 

#### 1. Теоретический обзор нейросетевых методов для определения состояния утомления/дремоты на основе анализа ЭЭГ/аудио сигналов человека. 
#### 2. Обзор открытых баз данных классификации состояний утомления/дремоты по ЭЭГ/аудио. Получение доступа к закрытым базам данных. Анализ количественного состава баз данных.
#### 3. Разработка процедур импорта и предобработки данных с помощью специализированных библиотек (mne/librose).
#### 4. Подбор и тестирование существующих нейросетевых методов классификации состояний утомления/дремоты на доступных базах данных.
#### 5. Теоретический обзор методов решения задачи учета межиндивидуальной и межгрупповой вариабельности характеристик ЭЭГ/аудио сигналов состояний утомления/дремоты.
#### 6. Применение методов кластеризации для выявления группирования экспериментальных данных по характеристикам ЭЭГ/аудио сигналов состояний утомления/дремоты.
#### 7. Подбор и тестирования существующих методов переноса обучения (transfer learning) для решения задачи учета межиндивидуальной и межгрупповой вариабельности ЭЭГ/аудио характеристик.
#### 8. Разработка оригинального нейросетевого метода распознавания утомления/дремота (нейросетевой классификатор) с встроенными механизмом учета индивидуальных ЭЭГ/аудио характеристик (нейросетевой модуль цифрового портрета человека).
#### 9. Разработка метода слияния ЭЭГ и аудио классификаторов состояний с обобщенным модулем цифрового портрета.
#### 10. Подготовка статей/докладов для высокорейтинговых журналов/конференций.
